# Fargeaula Ops

Fargeaula Ops is an Android operations workspace for FOYER 3 EME AGE CLUB FARGEAULAIS.

The app supports local appointment booking, shipment logging, quality checklist review, and employee directory coordination. Records are stored on the device in local app storage; the app does not use accounts, cloud sync, analytics, external APIs, or Android permission requests.

Release materials are generated under `docs/`, and the standalone static landing page is in `web/`.
